We focus on products that are useful in real life: tools that help people plan better, host faster, understand usage, publish knowledge, and automate the work that should not need repeated manual effort.

## Engineering Principles

- **Privacy by default**: Personal systems should ask before keeping sensitive information.
- **Low operational overhead**: Prefer simple, observable, maintainable infrastructure.
- **Useful automation**: Automate repetitive work without removing human control.
- **Product discipline**: Build small, verify often, and document the decisions that matter.

## Core Stack

Our projects commonly use:

- Cloudflare Workers, D1, R2, Pages, and Workflows
- Nuxt, Vue, TypeScript, and pnpm workspaces
- Native macOS and mobile clients where platform integration matters
- GitHub Actions and reusable infrastructure workflows
